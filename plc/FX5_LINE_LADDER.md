# FX 风格梯形图网络 / FXスタイルラダー回路

> 独立训练示例。以下助记表达用于解释逻辑分层，不是任何厂商工程文件的复制，也不能直接作为安全程序投产。实际项目必须在工程软件中按 CPU、I/O 极性、定时器单位和安全规范重新验证。

## N01 安全输入汇总 / 安全入力まとめ

```text
|----[ X0 急停反馈 ]----[ X1 门关闭 ]----[ X2 驱动正常 ]----( M2 安全输入OK )----|
```

X0、X1、X2 是经硬件安全回路提供给普通 PLC 的状态反馈。危险能量切断不能只依赖 M2 或普通输出。

## N02 复位许可锁存 / リセット許可ラッチ

```text
|----[ M2 ]----[ ↑ M1 HMI复位要求 ]--------------------------------( SET M0 )----|
|----[/X0 ]----------------------------------------------------------( RST M0 )----|
|----[/X1 ]----------------------------------------------------------( RST M0 )----|
|----[/X2 ]----------------------------------------------------------( RST M0 )----|
```

## N03 自动运行锁存 / 自動運転ラッチ

```text
|----[ M0 ]----[ M10 自动模式 ]----[ ↑ M11 启动 ]----[ D30 = K0 ]----( SET M20 )----|
|----[ ↑ M12 停止 ]--------------------------------------------------( RST M20 )----|
|----[/M0 ]-----------------------------------------------------------( RST M20 )----|
|----[/M31 HMI心跳 ]--------------------------------------------------( RST M20 )----|
```

通信超时采用受控停止；急停和安全门仍由独立的硬件安全功能处理。

## N04 顺序步进 / シーケンスステップ

```text
|----[ M20 ]----[ D0 = K10 ]------------------------( Y0 电动进料 )----|
|----[ D0 = K10 ]----[ X3 到位 ]--------------------[ MOV K20 D0 ]----|

|----[ M20 ]----[ D0 = K20 ]------------------------( Y1 工艺伺服 )----|
|----[ D0 = K20 ]----[ X4 到位 ]--------------------[ MOV K30 D0 ]----|

|----[ M20 ]----[ D0 = K40 ]------------------------( Y2 检测触发 )----|
|----[ D0 = K40 ]----[ X5 到位 ]--------------------[ MOV K50 D0 ]----|

|----[ D0 = K50 ]----[/X6 合格 ]--------------------( Y3 电动剔除 )----|
|----[ D0 = K60 ]-----------------------------------[ INC D20 ]-------|
```

## N05 HMI 心跳 / HMIハートビート

```text
|----[ M100 与上次不同 ]----------------------------[ RST T100 ]------|
|----[/T100 ]----------------------------------------( M31 通信正常 )--|
|----[ T100 K30 ]------------------------------------( 3.0 s )---------|
```

HMI 每 500 ms 翻转 M100。PLC 应检测“变化”而不是只检测 ON，否则冻结在 ON 的通信数据会被误判为正常。

## N06 数据区 / データ領域

| 软元件 | 功能 | 写入方 | 校验 |
|---|---|---|---|
| D0 | 当前顺序步 | PLC | HMI 只读 |
| D20–D25 | 总数、良品、剔除 | PLC | 双字计数 |
| D30 | 当前报警码 | PLC | 0 = 无报警 |
| D100–D105 | 配方 | HMI | 停机写入 + 回读一致 |
| M10–M12 | 模式、启停请求 | HMI | 启停使用脉冲 |
| M100 | HMI 心跳 | HMI | 500 ms 翻转 |
